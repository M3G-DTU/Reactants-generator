# Reactants Generator
This repository contains a Python script that generates potential reactant candidates for a given reaction by analyzing the electrophilic and nucleophilic properties of the atoms in the reactants. 

Currently the script uses data from FDL or FMO calculations performed in AMS to identify potential interactions between electrophilic and nucleophilic atoms, and then rearranges the molecules accordingly to create new candidate structures.
